# fp32-normalize 大纲：规格化

## 观众起点与问题

- 系列与位置：「FP32 是怎么计算的」第 3 集；前置集是 `fp32-format` 与 `fp32-mul`。默认起点是高中数学和进制转换；只回顾第 1 集的规格化形式、阶码、隐藏位，以及第 2 集的阶码和和 48 位尾数积。第 4 集的舍入规则不是本集先修知识。
- 情景里的需求：推理芯片要把刚算出的乘积交给后面的计算。下一次乘加仍按同一种 FP32 格式读取它，尾数必须先回到小数点前恰好一个 1 的形式。
- 问题：`1.5 × 1.5 = 2.25`，尾数积的最高位到了第 47 位；怎样调回规格化形式，同时留下右移时掉出的信息？
- 开场三句的逻辑：推理芯片继续使用乘积 → 上集留下的积可能有两位整数 → 以 `1.5 × 1.5` 追问怎样调回 `1.F × 2^指数`，以及移出的最低位怎么办。片头卡不能代替这三句。
- 贯穿例子：`3FC00000 × 3FC00000`。上集只展示最高位为 1；本集把 `900000000000` 调成 `480000000000`，阶码和 `127` 调成 `128`，验算 `1.001₂ × 2¹ = 2.25`。用上集主例 `3F800001 × 3FC00000` 对照“不移动”的分支。用 `3FC00001 × 3FC00001` 说明掉出的原始 bit 0 为 1。

## 小节与核心公式

片头后分「为什么要调」「两条路径」「掉出的位」「画成结构」四部分；原理段和代码段各有一张约 1.5 秒的无旁白部件卡。小节前留 0.8–1.2 秒；每个小节第一句接住上一节的问题。

| 部分 | 小节 | 承接与画面推进 |
|---|---|---|
| 开场 | 写回还认不认得 | 上集的 48 位积要写回 FP32；主例的 `10.01₂` 摆在 `1.F` 入口旁 |
| 01 为什么要调 | 最高位在哪里 | 两条位条先显示首位位置，再命名「规格化」 |
| 02 两条路径 | 首位没越界 | 对照例最高位为 0，位条和阶码均直通 |
| 02 | 首位越界 | 主例 `10.01₂` 右移成 `1.001₂`，阶码同步加一，再验算 `2.25` |
| 03 掉出的位 | 最右边还有什么 | 原始 bit 0 离开位条；先看实物，再命名「掉出的位」 |
| 03 | 留给舍入 | 把原始 bit 1 和 bit 0 做或写到新 bit 0，只保留「后面有没有 1」 |
| 04 画成结构 | 两路选择 | 顶部规则对到 `if/else`、右移连线、加法器、或门和选择器 |
| 04 | 送往下一步 | 两个分支各走一次，低位信息交给下一集舍入 |

顶部常驻「48 位尾数积 → 首位判断 → 调整后积」与并行的「阶码和 → +0 / +1 → 调整后阶码」。蓝色积、陶土色阶码、绿色掉出的位依次亮起。这里只展示中间值，不把舍入后的 FP32 编码当作本集产出。

## 类比

- `22.5 × 10³ = 2.25 × 10⁴` 与 `10.01₂ × 2⁰ = 1.001₂ × 2¹` 严格等价在“有效数除以进制底数，指数加一，整体数值不变”。十进制只是回顾科学计数法的补偿关系；位条移动仍用二进制主例讲。

## 角色色与画面计划

- 蓝色：尾数积与调整后积，沿用第 1、2 集尾数的蓝。陶土色：阶码和与调整后阶码，沿用阶码的陶土色。绿色：右移时掉出的原始 bit 0 与并回路径；第 4 集才完整讲粘滞位。符号位本集不展开，避免与绿色角色同屏冲突。
- 开场与原理：顶部两路结构常驻；内容区先看两条 48 位位条的最高位，再让主例位条移动、阶码变动，最后放大末端一位并画出或门。一步只变一个状态。

## 论断边界

- `[1,4)` 与“最多右移一次”只针对两个规格化、非特殊输入的尾数乘法。零、非规格数、无穷、NaN 的分类已在前两集讲过，不把特殊路径的中间位串解释成普通规格化。
- 纯右移会丢掉原始 bit 0。源码把它与原始 bit 1 做或写回新 bit 0；这个位不再是精确数学积的最低位，只代表被压缩的尾部是否有 1。不能把整个 `prod_n` 称作精确乘积；这项信息足以供第 4 集作粘滞位判断。
- 调整后阶码仍是带偏置的中间阶码，尚未检查能否写入 8 位；第 4 集舍入，第 5 集处理进位与上下溢。这里不展示特殊范围案例的最终编码。
- `reg` 是 Verilog 的过程赋值类型名，不能由字面推断有时钟寄存器。本段 `always @(*)` 没有时钟沿，两个分支均给两项输出赋值；画面只画组合选择，不画额外寄存器或多一拍延迟。
