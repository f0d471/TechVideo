# 新集骨架与风格参照

`vt new` 复制本目录作为立项骨架。现行整集模板是第 6 集 [fp32-pipeline](../fp32-pipeline/) 的验收通过版本，阅读顺序、旁白原句与代表场景见 [风格模板](../../docs/standards/reference.md)。

- 大纲：从本集的情景需求排概念链，参照第 6 集 `outline.md` 的依赖与画法对应关系。
- 脚本：先写连贯的小节，再按画面变化切成 beat；平实讲清操作、原因与结果，首次命名时补行业英文名或缩写。
- 编排：参照第 6 集 `Video.tsx` 的核心公式条、章节卡、小节标签和场景退出，把占位内容换成本集的概念。
- 原理画面：按内容使用电路、时序图、公式或逐拍表格，说明在上、主体在中、字幕在底部，角色色贯穿各段。
- 代码画面：默认代码在上、电路在下；面板容纳原代码的最长行，部件与导线共用坐标，讲到哪一行才出现相应结构。
- 配音：骨架使用系列现行音色 `zh-CN-YunxiNeural` 与速率 `+4%`，语速和片长由 `vt tts` 检查。

每集仍按 [S0–S8 流程](../../docs/sop.md) 制作，具体规范在 [docs/standards/](../../docs/standards/)。
