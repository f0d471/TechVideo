# 审稿与画面审查

一集从立项做到成片由制作方一次做完，中途没有人工审阅；人工只在 S7 看成片。脚本和画面的质量由这里的两道审查把关：S3 的审稿（配音之前）和 S5 的画面审查（出片之前）。

## 一、谁来审

审查由没有参与写这一版的上下文来做：能开子 agent 的环境开一个子 agent，否则开一个新会话。审查方只拿到本文件列出的材料，不看写稿过程和制作方的解释。它的任务是找问题，不是确认通过：先逐条写下发现的问题，再给结论。

写稿的上下文自己检查一遍不算审稿。首稿 fp32-format 就是写稿方自己记了「审阅通过」，偏差全部留到了成片里。

## 二、审稿（S3，配音之前）

材料：本文件、`docs/standards/` 下的四份规范、系列大纲里这一集的条目、这一集的 `outline.md`、`build/script.md`（`vt table` 生成）、`vt lint` 的输出，以及参照成片的 `videos/fp32-rne/script.json`。

逐条检查下表。每条写结论（通过或修改）和证据，证据是页码加一句话，不能只写「通过」。

| 编号 | 查什么 | 依据 |
|---|---|---|
| R1 | 开场：前三句旁白说出这一集要解决的问题；合成的一集，每部分的第一句交代它回答问题的哪一半 | `principle.md` 第十节 |
| R2 | 概念：没有先用后讲；旁白和画面要用的术语都在 `concepts.json` 里或属于观众起点，用的是标准叫法 | `principle.md` 第二节、`curriculum/README.md` |
| R3 | 例子：只看例子，得出的结论和旁白说的一致；例子覆盖情景里的理由；没有要靠「反而」「这个例子里」解释的行，没有构造出来的巧合 | `principle.md` 第十二节 |
| R4 | 理由与代价：取舍的理由照系列大纲；代价讲一次并放回情景；没有防御性限定和计划外的反例；偏离系列大纲的地方都写在 `outline.md` | `principle.md` 第八、十一节，`narration.md` 第三节 |
| R5 | 推进：每句推进一个状态，没有空过渡句；结构相同的代码行（a、b 各一份）合成一句 | `narration.md` 第一、三节，`code.md` 第二节 |
| R6 | 说法：朗读和字幕说的是同一个名字；没有禁用句式、制作视角用语、自问自答 | `narration.md` 第二、三节 |
| R7 | 代码段：开头回到原理段最后那条规则；翻译级别按 `terms.json`，翻译用词汇表的原词；最后用开头的例子送进电路验证 | `code.md` 第二、四节，`principle.md` 第九节 |
| R8 | 数字：每个数都在 `outline.md` 的数字清单里，出处类型和来源写清 | `principle.md` 第七节 |
| R9 | 对照参照成片：和 `fp32-rne` 的脚本并排读，开场、句子、代码段讲法在同一水准；列出明显不如参照的页 | `AGENTS.md` |
| R10 | 检查：`vt lint` 零错误，每条提醒都有处理结论 | `sop.md` S3 |

有一条是「修改」，就改脚本、重新 `vt table`，再从头审一遍（新的脚本指纹，新的审稿记录）。

## 三、记录格式

审稿记录写进这一集 `STATUS.md` 的「脚本审稿」，一个脚本指纹一节。`vt tts` 按这个格式核对：当前指纹要有一节，R1–R10 每条都在，结论都是「通过」，证据不为空；缺一条就不配音。

```
### 审稿 0c46c697af15

审稿方：子 agent（或：新会话），2026-09-28

| 编号 | 结论 | 证据 |
|---|---|---|
| R1 | 通过 | p01–p03：加速器里的数范围很宽 → 32 位怎么放 → 极小的数要不要管 |
| R2 | 通过 | …… |
```

S7 审片通过的成片，它的脚本指纹记在「审片通过」表里；`vt tts` 对这样的指纹不再要求审稿记录（克隆后重新生成配音时用）。

## 四、画面审查（S5，出片之前）

材料：本文件、`docs/standards/visual.md`、`docs/standards/code.md` 第五、六节、这一集的 `outline.md`、`vt stills <id> 0.5 --all` 生成的四宫格，以及参照成片同一段落的四宫格。

审查方按 `visual.md` 第六节的自查清单逐张看四宫格，每一条清单写结论和有问题的页码。有问题的页改完重新抽帧，再看一遍改过的页。记录写进 `STATUS.md` 的「画面审查」，格式同上，编号用清单条目的名字（安全区、遮挡、断行……）。

## 五、交片

S6 出片后，在 `STATUS.md` 的「交片说明」写三五行，交付时一并给出：片长；偏离系列大纲的地方，一条一句；审片时值得留意的地方（例如没有登记过读音的多音字所在页）。审片只看成片和这几行。
