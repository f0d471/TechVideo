# 文案与朗读规范

旁白是写给耳朵的。耳朵不能回看，所以一句只讲一件事，画面负责把「是什么」摆出来，旁白负责说「为什么」和「接下来看哪里」。本文件中能机器判断的规则由 `tools/lint_script.mjs` 检查，数值界限在 `tools/limits.json`，读音由 `tools/lexicon.json` 处理。

## 一、beat 与句子

- 一个 beat 是一句旁白加一次画面变化。旁白说到哪，画面就变到哪；一个 beat 里不推进两件事。
- 一句不超过 50 个字（不计标点），超过就拆成两个 beat。
- 字幕区宽 1500 像素、字号 40 像素，最多两行。换行位置由 `sub` 里的 `\n` 写明，只放在标点后，画面不自动折行，所以一个词不会被拆到两行。`vt lint` 按汉字与全角标点 1 em、其余字符 0.6 em 估计每行宽度，超宽的行报错；一行放得下的字幕不加换行。换行不改变脚本指纹。
- 需要观众停下来看画面的地方，用 `hold` 加 0.4–1.2 秒停留，不靠旁白里的「我们停一下」。

## 二、`say` 与 `sub`

`say` 送给 TTS，`sub` 是字幕。两者意思相同，写法按用途分开：

| 内容 | 字幕 `sub` | 朗读 `say` |
|---|---|---|
| 数字 | 阿拉伯数字：`48 位`、`0.5` | 汉字：`四十八位`、`零点五` |
| 代码记号 | 原样：`prod_n[22]`、`|`、`&` | 读法：`prod n`、`方括号里的二十二`、`竖线`、`这个符号` |
| 英文缩写 | 原样：`lsb` | 拆字母：`L S B` |
| 标准名 | `IEEE 754` | `浮点标准` |
| 概念名 | `curriculum/concepts.json` 的 `name` | 同左；`avoid` 里的别名 `lint` 会提醒 |

`say` 里不许出现阿拉伯数字和代码符号，`lint` 会报错。

## 三、禁用句式

下面这些句式在审片中被判为「AI 腔」，字幕和朗读都不用。`lint` 会报错的写在前一栏。

| 句式 | 说明 | 改法 |
|---|---|---|
| 不是……而是……、并不是、而是 | 先否定一个没人提出的说法，再立论 | 直接陈述是什么：「在电路里，这一行对应一根线」 |
| 正是、恰恰 | 强调语气 | 删掉，或换成「属于」「就是」 |
| 这就是……、这便是…… | 总结句 | 「这个规则叫……」 |
| 其实、事实上、实际上 | 暗示观众原来想错了 | 删掉 |
| 本质上、说白了、换句话说、简单来说 | 换说法的套话 | 只说一遍，说清楚 |
| 值得注意、需要注意、注意， | 提示语 | 用画面强调，旁白直接说内容 |
| 关键在于、核心在于、奥秘 | 拔高 | 删掉 |
| 让我们、我们来看、你会发现、不难发现、没错、答案是 | 口播套话 | 删掉 |
| 破折号、感叹号 | 书面腔或煽情 | 用逗号、句号 |

`lint` 不报错、但同样要避免的写法：

- 设问后自己回答（「该往哪边走？」「答案是……」）。`lint` 对问号给提醒，保留问句要能说出理由。
- 冒号后揭晓（「麻烦出在正中间：……」）。冒号只用于列举和给出规则本身。
- 三连排比、对仗式的收尾句。

## 四、读音

- 多音字在朗读文本里换成同音的单音字，字幕不动。替换规则写在 `tools/lexicon.json` 的 `replace`，由 `tools/build_audio.py` 在合成前统一执行。现有规则：「行」在数字和「这、下、每」等字后面读 háng，替换成「杭」。
- `lexicon.json` 的 `polyphones` 列出技术旁白里容易读错的多音字。`lint` 会对这些字给提醒，除非它落在 `confirmed` 登记过的词语里。听过读音确认无误的词语，连同依据一起加进 `confirmed`。
- 回听校对（`vt asr`）能发现读错的音节，但查不出多音字：识别模型会按上下文写出正确的字。多音字靠 `lint` 提醒和审片把关。

## 五、配音参数

- 音色：`zh-CN-YunxiNeural`（edge-tts）。审片认可，可继续使用；想要更有辨识度的声音，可换本地 IndexTTS2 克隆固定的参考音色，流程不变。
- 速率：`+0%`，句间停顿 10 帧（`gapFrames`），每句前导 4 帧（`leadFrames`）。
- 语速要落在 4.8–5.3 字/秒（不计标点）。`vt tts` 完成后计算全片平均语速，超出区间时退出码为 1，调整 `script.json` 的 `rate` 后重跑。4.59 字/秒在审片中判为偏慢，4.94 字/秒通过。
- 一句一个音频文件，首尾静音自动去掉；句间停顿由时间轴控制，不在文本里加停顿标记。

## 六、内容写法

- 口播讲为什么、看哪里；屏幕上已经写出的公式和代码，旁白只说意思，不逐字念。
- 新名词先说它是什么，下一句再给名字（「被扔掉的第一位……它叫保护位」）。
- 名字有来由的，说一句来由（「粘滞位，意思是沾上一个 1 就甩不掉」）。
- 例子贯穿全集：开头出现的例子，在规则讲完后代回去验证一次。
