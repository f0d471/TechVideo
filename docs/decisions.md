# 裁决与反馈记录

按日期记下已定的裁决和审片反馈。规范文件只写当前规则，本文件记规则从哪里来。被推翻的做法保留在这里并注明推翻原因。

## 2026-09-26 定位

- 讲通用知识，不讲某个项目。素材代码来自具体仓库，但视频里只出现代码本身，不出现仓库或项目名。
- 对标 Core Dumped 的结构动画和 3Blue1Brown 的「一次只变一处」。浅色暖底，不用黑底；视觉效果的上限是手绘。
- 观众起点：高中数学，会任意进制转换；其余概念第一次出现就拆开，不重要的一句话带过。
- 每集原理在前、代码在后，中间用同一条规则或同一张框图过渡；需求和模型在原理段讲完。
- 代码逐字引用，只折叠不改写。
- 被讲解实现对标准的有意偏离（例如 FTZ）当作一个独立概念讲。
- 旁白用 TTS，脚本先定稿再合成。投放以 B 站为主，字幕烧进画面并另出 SRT；不配 BGM。单集 8–12 分钟（2026-09-28 推翻：改为一集一个概念，片长随概念，见当日记录）。
- 代码课在「逐词翻译、语法、结构」三层之外，为 Verilog 加「代码到电路」一层，理由：Verilog 描述同时存在的连线，按顺序执行的读法会读错。
- 同形记号按位置翻译。`wire`/`assign` 里的 `=` 译成连线；表达式里的 `<=` 是比较；时钟块语句开头的 `<=` 是存进寄存器。只把 Verilog 统一译成「连线」会译错后两种。

## 2026-09-26 技术选型

- 主栈 Remotion，不引入 Manim。理由：素材多为位域、代码、电路这类离散结构，SVG 是它们的原生表达；任意帧可单独渲染，agent 能抽帧自查；配色即 CSS 变量，中文字体直接可用；代码课需要逐记号高亮。
- 字幕与动画的时间由分句 TTS 的时长累加得到，不做整段合成后的强制对齐。
- 装 Remotion 官方 skill；不装第三方的 Remotion 风格 skill（其胶片颗粒、调色等效果与定位冲突）；3b1b 的仓库当参考教材，不当工具。

## 2026-09-26 样片 fp32-rne 自查中发现的问题

- 画面遮挡 6 处，已修，规则并入 `docs/standards/visual.md` 的自查清单。
- JetBrains Mono 默认开连字，会把 `<=` 画成 ≤。等宽字体一律关闭连字。
- 回听校对按字比对会被识别端的同音字淹没（38 句里 15 句报错），改为拼音层比对后只剩真正需要判断的句子。

## 2026-09-27 仓库结构

- 以视频为单位组织：每集的源文件、配音、生成物都在 `videos/<id>/` 下，Remotion 的静态资源目录设为 `videos/`。
- 共享层分 `src/core/`（底座）与 `src/components/`（跨集组件）；新组件在第二次被用到时才提取为共享组件。
- skill 的真实文件放 `.agents/skills/`，`.claude/skills/` 放目录链接；`AGENTS.md` 是所有 agent 的入口，`CLAUDE.md` 引用它。
- 渲染用本机 Chrome，回归基准记录 Chrome 版本。回归判据：逐字节相同或 PSNR ≥ 60 dB 视为未变（同一浏览器连续出图的亚像素抖动实测 95–99 dB）。
- 重构后的验证：重构前后同一时间轴下 78 帧回归，77 帧逐字节相同，1 帧亚像素抖动。

## 2026-09-28 一集一个概念

- 一集只讲一个概念，片长随概念，区间 3–8 分钟；几个小概念撑不起一集时并成一集。推翻 2026-09-26 的「单集 8–12 分钟」：按概念切分后每集只回答一个问题，观众可以按需只看其中一集，规划与复用也以概念为单位。
- fp32-rne 从「E3 规格化与舍入的一部分」改为浮点乘法系列的第 6 集，作为完整一集的参照成片。
- 概念在素材里没有直接对应的代码时，这一集只有原理段。
- 系列规划、概念表、代码词汇表、素材登记集中在 `curriculum/`，由 `vt curriculum` 检查概念依赖不越过系列顺序。
- 乘法没有加法里的「对阶」：阶码直接相加。对阶留给以后的加法系列。

## 2026-09-28 开源发布

- 许可证：代码 MIT（`LICENSE`），内容 CC BY-NC-SA 4.0（`LICENSE-CONTENT.md`）。
- 仓库里不写本机绝对路径。本机设置进 `tools/env.local.json`（不入库）；Chrome 位置自动探测。
- 素材源码按 `curriculum/sources.json` 固定的提交号读取，不再用指向仓库外的相对路径；本地克隆的工作区状态不影响抽出的代码与仿真。
- 生成物里只有 `build/manifest.json` 与 `build/code.json` 入库：画面代码直接引用它们，入库后克隆下来就能类型检查和预览。配音、字幕、校对结果、成片不入库。
- Remotion 官方 skill 不入库：上游仓库没有声明许可证。来源与哈希记在 `skills-lock.json`，克隆后用 `npx skills experimental_install` 恢复。
- 方案展示页的源文件移出仓库。它是方案评审时的快照，其中的系列规划已并入 `curriculum/`；对外展示由 `README.md` 承担。
- bash 侧步骤在 Linux 与 macOS 上直接运行，Windows 上转给 WSL。
